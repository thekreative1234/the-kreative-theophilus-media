HOW TO OPEN THE WEBSITE ON YOUR LAPTOP
1. Download and extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html. It should open in your default web browser.
4. Click the category filters and test the phone, email, and WhatsApp links.

HOW TO UPDATE THE FILES
1. Right-click index.html and choose Open with > Notepad (or use a code editor).
2. Make text changes, then press Ctrl+S to save.
3. Open style.css to change colours/layout.
4. Open script.js to change interactive behaviour.
5. Refresh the browser tab to see your changes.

BEFORE PUBLISHING
- Replace sample portfolio artwork cards with your actual flyer images.

HOW TO ADD YOUR PORTRAIT
1. Copy your picture into the images folder and name it portrait.jpg.
2. In index.html, find the <div class="portrait-placeholder"> ... </div> block.
3. Replace that entire block with:
   <img class="portrait-photo" src="images/portrait.jpg" alt="The Kreative Theophilus">
4. Add this to the end of style.css:
   .portrait-photo { width:100%; aspect-ratio:3/4; object-fit:cover; display:block; }
